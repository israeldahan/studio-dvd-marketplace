# מבנה תיקיות

## תיקיית לקוח (קיימת, לא מסדרים מחדש בלי אישור)

```
<לקוח>/
  <תיקיית תוויות>/            למשל: תויות לגרביים
    ברקודים/                  barcode_<דגם>.png / .pdf / .svg
    איורים/                   איורים קוויים לפי סוג מוצר
    <פלטות>.ai                למשל BOND_master_palette_96.ai
    <תוויות קודמות>.ai/.pdf   למשל BOND_tiket sokcs_<דגם>.ai
    תוית <דגם או שבלונה>/     תיקייה לכל תווית חדשה (ראו למטה)
```

## תיקייה לכל תווית חדשה

ממליצים לפתוח תיקייה אחת לכל דגם חדש, בתוך תיקיית התוויות:

```
תוית <דגם> - <שבלונה>/        למשל: תוית 896 - X2526
  <שבלונה>.pdf                הקובץ מהסטנסלר, בדיוק כמו שהגיע. לא עורכים אותו.
  פרטי דגם.txt                המקור היחיד לטקסטים. דבי עורכת אותו.
  <שם תווית>.ai               קובץ העבודה, לפי מוסכמת השמות של הלקוח
  תצוגה/                      PNG ו-PDF לאישור, ומפת האזורים
```

- את הברקוד משאירים בתיקייה המשותפת `ברקודים/` בשם `barcode_<דגם>.*`, כדי שהבדיקה תמצא אותו.
- לא מעבירים לשם קבצים קיימים. מעתיקים.
- שם קובץ העבודה ממשיך את המוסכמה של הלקוח. אצל BOND: `BOND_tiket sokcs_<דגם>_<שבלונה>.ai`.

## מה עוזר לעבוד מהר

- **שבלונה אחת בתיקיית הדגם.** אם יש כמה גרסאות, שמים בתיקייה רק את הגרסה הסופית.
- **`פרטי דגם.txt` מלא לפני שמתחילים.** הבדיקה `check_model_folder.py` מראה מה חסר.
- **תמונה של תווית מקופלת**, אם יש לכם, בתיקייה `תצוגה/`. היא עוזרת להכריע מה חזית ומה גב.
